# ADOT — Asian Distance Optimization Table

**Live:** https://adot-research.web.app/

Research site for ADOT: an ADOT/VDOT calculator, the D0 evidence (34,139 marathon finishers), the experiment programme (E0a–E4, E2', E3') and the D0–D4 roadmap.

## Layout

```
adot/
├── firebase.json     # Hosting → public/
├── .firebaserc       # default project: adot-research
└── public/index.html # single-file site (JA/EN), no build step
```

## Deploy

```bash
firebase deploy --only hosting
```
